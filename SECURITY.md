# Security reports

Please do not put passwords, OAuth tokens, recordings, transcripts or unredacted
logs in public issues. Reproduce ordinary bugs with synthetic media and remove
local usernames and paths from attachments.

For a vulnerability that could expose credentials or execute untrusted code,
use GitHub's **Security → Report a vulnerability** if available. If private
reporting is unavailable, use a private contact method explicitly listed on the
maintainer's GitHub profile, or open a minimal issue requesting a private channel
without disclosing exploit details or sensitive data.

This is an early-stage personal project. No response-time guarantee or
independent security audit is claimed. Fixes target the current main branch.
The optional ChatGPT integration has local protocol tests; real account login
and inference have not been validated. See `STATUS.md` for testing limits.
