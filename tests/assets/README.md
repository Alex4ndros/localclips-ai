# Test asset attribution

`astronaut.png` is the NASA photograph of Eileen Collins distributed with
scikit-image v0.24.0 as `data.astronaut`, documented as public domain:
https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut

It is used only to test face detection, not identity recognition. All desktop
video fixtures are generated locally by the tests; no user recordings are included.
